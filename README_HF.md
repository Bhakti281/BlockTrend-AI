# BlockTrend-AI ⚡

The AI-first crypto intelligence platform — Predict market moves with Random Forest, XGBoost, and LSTM. Understand every call with SHAP explanations.

## Features

- 🏠 **Market Dashboard** — Live crypto prices and market overview
- 📈 **TradingView Charts** — Professional-grade charts with RSI, MACD, Bollinger Bands
- 🤖 **AI Signals** — ML ensemble predictions with SHAP-explained feature importance
- 🪙 **Multi-Coin Analysis** — Compare BTC, ETH, SOL, ADA, BNB, XRP side-by-side
- ⚡ **Latency Check** — Real-time API latency monitoring

## Tech Stack

- **Frontend**: Gradio (Python)
- **Data**: CoinGecko API (real-time crypto data)
- **Charts**: TradingView Widgets
- **ML Models**: Random Forest, XGBoost, LSTM (ensemble)
- **Explainability**: SHAP feature importance

## Deployment

This app is deployed on Hugging Face Spaces using Gradio SDK.
